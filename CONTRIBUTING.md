# Contributing to Awesome Vibe-Code Security

PRs are welcome! To keep this list genuinely useful for builders shipping production web apps:

1. **Concrete over generic:** Link directly to a working open-source tool, official doc, reproducible benchmark, or actionable technical guide.
2. **No pure landing pages:** Commercial services without a free tool, open-source repo, or concrete technical guide will be declined.
3. **One line per entry:** `- [Name](https://url) - One concise sentence explaining what it actually checks or solves.`
4. **Check duplicates** and keep alphabetical or logical order within each section.
5. **Disclose affiliation:** If you made or work on what you are adding, say so in the PR. Entries from the list maintainers (Shipmate) end in `(Shipmate)` and go after third-party entries in each section.
6. **Lint before opening a PR:** `npx awesome-lint`.
